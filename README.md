Presentación interactiva institucional y estratégica para **Vibra Más**, diseñada con formato 16:9, animaciones de transición fluidas, paleta corporativa y controles completos de exposición.

🔗 **Visualización en Vivo (GitHub Pages):**  
👉 **[https://jamesraynor007.github.io/PresentacionVIbraMas/](https://jamesraynor007.github.io/PresentacionVIbraMas/)**

## 🖥️ Características de la Presentación

- **Estructura 16:9 Adaptable:** Se adapta automáticamente a cualquier monitor, proyector o pantalla móvil.
- **Navegación Intuitiva:**
  - `→` / `Espacio` / `AvPág`: Siguiente diapositiva.
  - `←` / `RePág`: Diapositiva anterior.
  - `F`: Modo pantalla completa (Fullscreen).
  - Gestos táctiles (*Swipe*) en smartphones y tablets.
- **Acceso Directo Cloud:** Enlace integrado a la carpeta oficial de Gobernanza en Google Drive.
- **Optimizado para Impresión:** Botón directo para imprimir o guardar como PDF (`Ctrl + P`).

## 🚀 Despliegue en GitHub Pages

1. En el repositorio de GitHub, dirígete a **Settings** > **Pages**.
2. En **Build and deployment**:
   - **Source:** Selecciona *Deploy from a branch*.
   - **Branch:** Selecciona `main` / `/(root)` y pulsa **Save**.
3. En breves instantes la presentación estará activa y disponible públicamente en la URL de GitHub Pages.
